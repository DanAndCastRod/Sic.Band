# [SIC] — Sistema de contenidos

## Principio

[SIC] no debe comportarse como una banda que simplemente publica contenido. Debe comportarse como un universo que produce señales, rastros, preguntas y materia.

Orientación general:

- ~70 % conceptual/narrativo;
- ~30 % musical/promocional/informativo.

No es una cuota rígida. La prioridad es que la promoción no rompa el universo.

## Territorios editoriales

### CONFLICT

Preguntas, contradicciones, frases y tensiones que provocan interpretación.

### MATTER

La música como materia: riffs, manos, cuerdas, batería, cables, pedales, amplificación, ensayo, errores y proceso.

### ARCHIVE

Historia y evolución de la banda tratadas como evidencia o documento recuperado.

### AMBIGUOUS

Verdad, percepción, conveniencia, interpretación y conflicto semántico. Mientras esté en desarrollo, presentarlo como señal parcial.

### LAB

Experimentos visuales y sonoros. El resultado puede ser inconcluso.

### LIVE

Cuerpo, energía real, escenario, público, fricción y performance.

### TRIAD

La formación actual de tres integrantes. Ver `03_MEMBER_IDENTITIES.md`.

## Estados visuales vs. territorios

No confundir categorías de contenido con estados visuales.

Territorios responden a **qué se está diciendo**:

`CONFLICT / MATTER / ARCHIVE / AMBIGUOUS / LAB / LIVE / TRIAD`

Estados responden a **cómo se manifiesta visualmente**:

`SILENCE / SIGNAL / TRACE`

Ejemplos:

- CONFLICT puede aparecer como SILENCE.
- MATTER puede aparecer como SILENCE o SIGNAL.
- ARCHIVE normalmente usa TRACE.
- LIVE normalmente usa SIGNAL.
- TRIAD puede usar SILENCE, SIGNAL o una composición editorial propia.

## Primera secuencia narrativa sugerida

1. MANIFIESTO — identidad.
2. LA PREGUNTA — duda.
3. IDEA → MATERIA — música.
4. ARCHIVE / ORIGEN — historia.
5. LA TRÍADA — formación actual.
6. SIC LAB / 001 — experimento.
7. LA CONTRADICCIÓN — participación.
8. SIGNAL — misterio.
9. AMBIGUOUS — revelación progresiva.
10. LA PUERTA — invitación.

Lógica:

`identidad → duda → música → origen → integrantes → experimento → participación → misterio → revelación → invitación`

## Reglas editoriales

- No repetir el mismo tipo de titular en todas las piezas.
- No usar siempre el logo grande.
- No usar siempre waveform.
- No usar siempre línea roja vertical.
- Evitar microtextos repetidos que terminen siendo decoración.
- Alternar intensidad: vacío, presencia, archivo, ruido, pausa.
- La fotografía de ausencia también es contenido: escenario vacío, micrófono, instrumento, cables, objetos.

## Language-light

El sistema debe poder funcionar globalmente.

Ejemplos de labels técnicos útiles:

- `SIGNAL`
- `SOURCE`
- `STATUS`
- `ARCHIVE`
- `CURRENT`

No abusar de ellos. Deben aportar contexto, no disfrazar la pieza de interfaz sci-fi.
