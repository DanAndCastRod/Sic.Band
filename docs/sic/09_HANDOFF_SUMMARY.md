# [SIC] — Resumen de continuidad / Handoff

Este documento existe para que Codex CLI, otros agentes o colaboradores puedan retomar el proyecto sin perder las decisiones principales del trabajo realizado.

## 1. Objetivos

### Objetivo estratégico

Construir un sistema de crecimiento digital para [SIC] que convierta curiosidad en escucha intencional y prepare una audiencia para la futura era `AMBIGUOUS`.

### Objetivo de marca

Refinar una identidad visual y narrativa global, coherente entre música, web, Instagram, archivo y futuras campañas.

### Objetivo visual

Crear un Key Visual System propio de [SIC], evitando caer en un lenguaje genérico de poster grunge/rock. El sistema debe poder oscilar entre silencio, tensión escénica y archivo sin perder identidad.

### Objetivo de implementación

Alinear progresivamente:

- repo/web;
- campañas;
- contenidos sociales;
- fotografía;
- archivo histórico;
- identidad de integrantes;
- tracking y escucha.

## 2. Decisiones tomadas y motivos

### Dirección editorial sobre promocional

**Decisión:** la identidad debe sentirse editorial, conceptual y documental antes que publicitaria.

**Motivo:** las primeras exploraciones parecían demasiado cercanas a afiches promocionales o carteles de combate y no representaban bien la profundidad conceptual de [SIC].

### Rostros como materia, no como concepto central

**Decisión:** los rostros pueden aparecer, pero no deben dominar por defecto.

**Motivo:** [SIC] funciona mejor cuando cuerpo, instrumento, gesto, silueta, ausencia y tensión escénica forman parte del arte. La banda debe seguir siendo reconocible sin depender del retrato heroico.

### Tensión escénica sobre pose

**Decisión:** priorizar imágenes de acción, interpretación y presencia real.

**Motivo:** las fotografías live transmiten mejor la energía y autenticidad de la banda que las poses promocionales tradicionales.

### Minimalismo real

**Decisión:** `menos es más` se adopta como regla operativa.

**Motivo:** varias versiones anteriores acumulaban textura, glitch, bordes, microtexto, collage y rojo hasta convertir el sistema en una fórmula genérica de rock alternativo.

### Blanco como campo principal posible

**Decisión:** blanco y negro son campos equivalentes del sistema.

**Motivo:** el blanco permite representar silencio, espera, idea, ausencia y archivo. Esto diferencia a [SIC] de identidades que dependen siempre de fondos negros y deterioro visual.

### Estados visuales `SILENCE / SIGNAL / TRACE`

**Decisión:** separar el sistema en tres estados visuales.

**Motivo:** permite variedad sin perder coherencia.

- `SILENCE`: vacío, blanco, baja densidad, idea.
- `SIGNAL`: tensión física, escenario, negro, presencia.
- `TRACE`: archivo, memoria, evidencia real.

### SILENCE como estado dominante

**Decisión:** usar aproximadamente `SILENCE 60 % / SIGNAL 25 % / TRACE 15 %` como orientación.

**Motivo:** si todo es ruido, ninguna pieza irrumpe. El silencio aumenta el impacto de SIGNAL y hace al sistema menos genérico.

### Rojo como señal táctica

**Decisión:** el rojo no es relleno decorativo.

**Motivo:** debe tener significado. Se definieron posibles comportamientos: `AXIS / FAULT / PULSE / TRACE`.

### No deformar fotografías

**Decisión:** nunca estirar imágenes horizontal o verticalmente.

**Motivo:** versiones previas deformaban cuerpos e instrumentos. Solo se permite escalado proporcional con recorte editorial o con aire/márgenes.

### TRACE debe ser verdadero

**Decisión:** usar únicamente metadata real.

**Motivo:** una pieza documental pierde sentido si inventa fechas, lugares, códigos o nombres de archivo.

### AMBIGUOUS todavía está en desarrollo

**Decisión:** comunicarlo como `AMBIGUOUS / SIGNAL IN DEVELOPMENT`.

**Motivo:** todavía está en composición y no debe parecer un lanzamiento terminado.

### Formación actual de tres integrantes

**Decisión:** `CURRENT / TRIAD` incluye solo a Daniel Castañeda, Juan Pablo Hurtado y Francisco Valencia.

**Motivo:** el archivo incluye una formación histórica con cuatro personas y debe evitarse cualquier confusión entre historia y formación actual.

## 6. Evolución del Key Visual System

### v1–v3

Las primeras versiones eran demasiado cercanas a manual corporativo / presentación de agencia. La composición era muy regular y varias imágenes estaban forzadas dentro de cajas.

### v4–v5

Se avanzó hacia editorial brutalista / archivo experimental / grunge, pero se detectó exceso de textura, collage, microtexto y recursos repetidos.

### v6

Se consolidó `SILENCE / SIGNAL / TRACE` y aumentó la coherencia, pero la estructura empezó a sentirse demasiado formulaica: línea roja vertical, waveform, logo y encabezados repetidos.

### v7

Es la referencia visual más madura hasta ahora.

Hallazgos:

- SILENCE es lo más distintivo.
- SIGNAL funciona mejor con menos decoración.
- MATTER gana fuerza con manos, instrumentos y objetos.
- TRACE requiere rigor documental.
- TRIAD necesita fidelidad facial alta.
- la identidad debe sobrevivir aun sin logo grande, waveform, línea roja o tipografía gigante.

## 8. Restricciones

- No deformar fotografías.
- No inventar metadata en TRACE.
- No intercambiar integrantes ni roles.
- No incluir antiguo integrante en CURRENT / TRIAD / campaña actual / AMBIGUOUS.
- No tratar AMBIGUOUS como lanzamiento terminado.
- No asumir que negro + rojo + grunge = identidad suficiente.
- No repetir waveform, línea roja o logo como plantilla obligatoria.
- No llenar todas las composiciones.
- No usar rostros genéricos para representar a la banda actual.
- No llevar la web a una estética que sacrifique usabilidad o acceso a escucha.
