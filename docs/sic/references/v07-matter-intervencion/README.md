# MATTER — Intervención sobre V07

El usuario descartó V08 como dirección artística por su vaciado y pérdida de carácter. Se retoma V07 y se interviene únicamente MATTER para evaluar el criterio antes de extenderlo al sistema.

[Comparación](comparacion.html) · [Original V07](matter_v07_original.png) · [Composición intervenida](matter_v07_composicion.png)

## Cambios

- La mano sobre el bajo se convierte en imagen dominante y su diagonal organiza el bloque inferior.
- Guitarra y batería actúan como apoyos superiores; la pedalera funciona como contrapeso inferior izquierdo.
- Se conserva el titular contundente, el collage, el tratamiento monocromo, la materialidad del papel y el wordmark.
- Se elimina la fotografía del micrófono, la nota manuscrita y los rótulos técnicos periféricos.
- Los gestos rojos se concentran en las uniones entre texto y fotografías; una cinta queda como unión material.

## Evaluación interna

La intervención recupera densidad y carácter frente a V08 y distingue mejor los pesos fotográficos que el original V07. No convierte el collage en una pieza de imagen única.

Quedan aspectos a discutir: las dos imágenes superiores todavía presentan una disposición bastante regular; el bajo tiene un protagonismo muy superior a los otros instrumentos. Esa diferencia es deliberada como jerarquía compositiva de MATTER, no como jerarquía entre integrantes.

Esta es una propuesta de composición generada con IA, pendiente de evaluación del usuario. No se declara aprobada ni se extiende a las demás piezas. No es una nueva versión del sistema.
