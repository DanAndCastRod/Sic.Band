## Regla de continuidad visual

Cuando se generen, editen o seleccionen imágenes para `CURRENT`, `TRIAD`, campaña, hero web, press kit o `AMBIGUOUS`, los sujetos deben corresponder a estos tres integrantes y respetar sus roles.

No sustituirlos por rostros genéricos.

No intercambiar instrumentos o roles.

El hecho de que el sistema visual oculte parcialmente rostros, use perfiles, sombras, manos o recortes no elimina esta regla. La identidad debe seguir siendo coherente.

## Uso por estado visual

### SILENCE

Puede mostrar fragmentos de cualquiera de los tres: manos, instrumento, perfil, espalda, silueta o ausencia.

### SIGNAL

Puede mostrar a los tres en acción escénica. La tensión y el gesto son más importantes que una pose limpia.

### TRACE

Puede incluir fotografías históricas reales, incluso de formaciones anteriores, siempre que el contexto lo haga explícito.

## Antiguos integrantes

El archivo histórico contiene imágenes de una formación anterior de cuatro personas.

Regla:

- `CURRENT / TRIAD`: nunca incluir antiguos integrantes.
- hero, campaña principal, press kit actual y AMBIGUOUS: nunca incluir antiguos integrantes.
- `ARCHIVE / TRACE`: sí puede incluirlos cuando la fotografía, fecha y contexto sean históricos y estén claramente etiquetados.
