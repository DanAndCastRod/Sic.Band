# [SIC] — Key Visual System

## Estado actual

La exploración visual evolucionó desde una estética demasiado cercana a “poster grunge” hacia un sistema más flexible y conceptual. La versión de referencia actual es **v7**.

La conclusión principal es que [SIC] no debe verse siempre roto, oscuro o saturado. El sistema funciona mejor cuando alterna **silencio, señal y rastro**.

## Estados visuales

### 1. SILENCE

Estado dominante del sistema.

Características:

- blanco dominante;
- mucho espacio negativo;
- fotografía parcial, pequeña o recortada;
- baja densidad visual;
- una frase o idea principal;
- una anomalía roja como máximo;
- tensión construida por ausencia y espera.

Usos recomendados:

- manifiestos;
- preguntas conceptuales;
- piezas de entrada;
- pausas dentro de una secuencia editorial;
- piezas donde la idea pesa más que la presencia física.

Referencias conceptuales validadas:

- `UNA IDEA NO PESA. / hasta que toca algo.`
- `NO BUSQUES UNA RESPUESTA. / entra en el conflicto.`
- `THE SIGNAL WAS HERE.`

### 2. SIGNAL

Estado de tensión física y escénica.

Características:

- negro dominante;
- fotografía live o de acción;
- cuerpo, instrumento, humo, luz, movimiento;
- contraste alto;
- intervención gráfica contenida;
- texto breve;
- ruido visual solo cuando aporta fricción.

Regla importante:

`SIGNAL` no significa “llenar de textura”. La energía debe provenir principalmente de la fotografía y el gesto.

### 3. TRACE

Estado documental y de memoria.

Características:

- archivo real;
- fotografías históricas reales;
- nombres de archivo reales;
- fechas y lugares reales solo cuando estén verificados;
- notas, cintas, setlists, capturas y documentos auténticos;
- composición que puede aceptar mayor densidad que SILENCE, pero debe seguir teniendo jerarquía.

Regla crítica:

> Nunca inventar metadata para TRACE.

Si no se conoce una fecha, lugar, código o contexto, debe omitirse o marcarse como no verificado.

## Distribución sugerida

Como guía editorial, no como cuota rígida:

- `SILENCE` ≈ 60 %
- `SIGNAL` ≈ 25 %
- `TRACE` ≈ 15 %

La razón es estratégica: si todo es ruido, nada irrumpe. El silencio hace que SIGNAL tenga mayor impacto cuando aparece.

## Gestos propietarios

El sistema puede usar una familia de gestos rojos, pero cada uno debe tener función.

### AXIS
Línea limpia que separa, ordena o divide significado.

### FAULT
Corte, interrupción o desplazamiento visual.

### PULSE
Señal corta, onda o variación sonora. No usar waveform en todas las piezas.

### TRACE
Marca residual: algo pasó y dejó huella.

## Reglas de fotografía

- Las imágenes nunca deben deformarse por estiramiento.
- Escalar siempre proporcionalmente.
- Si hace falta llenar un módulo, recortar de forma editorial sin deformar.
- El rostro puede aparecer, pero no debe dominar por defecto.
- Priorizar manos, instrumentos, siluetas, perfiles, cabello, espalda, postura, pies, cables, micrófonos, batería y objetos.
- `CURRENT / TRIAD` debe representar siempre la formación actual.

## Continuidad de identidad

Cuando aparezcan los integrantes actuales, conservar su identidad real aunque la imagen los muestre parcialmente, en sombra o en acción.

Ver `03_MEMBER_IDENTITIES.md`.

## Reglas de composición

- Una pieza puede ser casi vacía.
- Otra puede ser físicamente intensa.
- Otra puede ser documental.
- No exigir el mismo encabezado, logo, waveform o línea roja en todas las piezas.
- La identidad debe sobrevivir aun cuando falten varios de esos elementos.
- Evitar convertir la retícula en decoración visible.
- Permitir asimetría, silencios, recortes y elementos parcialmente fuera de cuadro.

## Regla de reducción

> Si un elemento no cambia la lectura conceptual, se elimina.

## Aplicaciones validadas

El sistema debe funcionar, como mínimo, en:

- hero web;
- manifiesto;
- publicación conceptual;
- reel cover;
- TRIAD;
- MATTER;
- TRACE / ARCHIVE;
- AMBIGUOUS / SIGNAL IN DEVELOPMENT;
- press kit;
- live visuals.

## Evaluación de la v7

La v7 es la exploración más madura hasta ahora, pero todavía no debe asumirse como sistema cerrado sin validación adicional.

Hallazgos positivos:

- SILENCE es la dirección más distintiva.
- SIGNAL funciona mejor cuando baja el ruido decorativo.
- MATTER es fuerte cuando usa manos, instrumentos y objetos.
- TRACE gana valor cuando usa metadata real.
- TRIAD necesita máxima fidelidad facial y de roles.

Riesgos todavía presentes:

- repetir demasiado la línea roja vertical;
- repetir waveform hasta volverlo decorativo;
- depender de tipografía gigante;
- convertir MATTER en collage automático;
- usar AMBIGUOUS como si fuera la identidad matriz;
- perder fidelidad de los integrantes en piezas generadas.

## Test de madurez

El sistema se considera suficientemente sólido cuando varias piezas claramente distintas se reconocen como [SIC] sin compartir una plantilla fija.

Prueba recomendada:

1. una pieza sin logo grande;
2. una pieza sin tipografía gigante;
3. una SILENCE casi vacía;
4. una SIGNAL escénica;
5. una TRACE estrictamente documental;
6. una TRIAD con identidad real y roles correctos.
